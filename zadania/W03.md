# W03 · Start obu usług jednym poleceniem

Wykonaj kartę na branchu `codex/web-preview` od rewizji ze scalonymi zależnościami.

**Wymaga** — W02, F05.  
**Odpowiadasz za** — compose.yaml, pliki budowania obrazów, .dockerignore i sekcja startowa README.md.

## Do wykonania

Z katalogu głównego polecenie docker compose up --build ma zbudować i uruchomić backend i frontend. Użyj Vite z proxy /api do usługi backend:8000 w sieci Compose. Przeglądarka otwiera http://localhost:5173 i wysyła żądania do tego samego origin. Udostępnij lokalnie port 8000 do inspekcji API. Użyj healthchecku i nazwanej przestrzeni danych backendu. Build bierze wersjonowane zależności obu usług i próbkę demonstracyjną. Wyklucz BACKUP, pliki scam_links.*, repozytorium Git i lokalne wyniki z kontekstu obrazu.

W README podaj wymaganie Docker z Compose, komendę startu i zatrzymania, adres podglądu, sposób odczytu logów i osobne komendy developerskie dla obu procesów. Pierwsze zbudowanie może pobierać obrazy i zależności.

## Odbiór

Na czystym checkoutcie z pustą przestrzenią danych uruchom dokładnie podaną komendę. Przez adres frontendu sprawdź health, uruchom przykład i otwórz rzeczywisty dowód. Po docker compose down i ponownym starcie zapisany przebieg jest dostępny. Sprawdź, że przy braku prywatnego korpusu i pliku .env nie trzeba ręcznie podawać zmiennych ani importować danych.
