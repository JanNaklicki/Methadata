# F05 · Frontend React i widok dowodów

Wykonaj kartę na branchu `codex/demo` od rewizji ze scalonymi zależnościami.

**Wymaga** — W01.  
**Odpowiadasz za** — frontend/ wraz z package.json, blokadą wersji i testami komponentów.

## Do wykonania

Zbuduj osobną aplikację React + TypeScript + Vite. Z kontraktu W01 wyprowadź typowany klient HTTP z bazą /api/v1. Ekran startowy pozwala uruchomić gotowy przykład, wkleić URL albo wybrać plik. Po wysłaniu materiału utwórz przebieg, zapisz run_id w adresie widoku i odpytuj API aż do stanu końcowego. Pokaż grupę, porównywane materiały i dostępne dowody z obu stron. Przy zamknięciu widoku zatrzymaj odpytywanie.

Do pracy równoległej użyj przykładów HTTP z W01 jako odpowiedzi testowych. Domyślna aplikacja używa rzeczywistego API i sygnalizuje utratę połączenia. Dowody tekstowe wyświetl jako tekst. Skonfiguruj proxy /api do adresu backendu podanego przez środowisko serwera Vite, z lokalnym domyślnym portem 8000.

## Odbiór

Z czystego frontend/ działają npm ci, npm run dev i npm run build. Testy obejmują plik, URL, demo, odświeżenie widoku przebiegu, sukces, niewystarczające dane, błąd API i pusty wynik. Serwer developerski używa portu 5173. W03 połączy oba procesy w jeden start.
